悉昙 IAST 输入法 · 操作说明（Mac）

macOS · Keyman v2.1 键盘 · 四层键位
字体：Noto Sans Siddham（随包安装）

开始之前，记住两条

① 辅音自带 a。按 k 出来的是 𑖎 ka——已经带了 a，不要再按 a。想打 kā 才需要额外按。

② 元音有两种形态。词首用独立形（𑖀 a），辅音后面用附标（𑖯 的 ā 记号）。选错了字就不成形。

1键盘长什么样

四个键位层，靠 ⇧ 和 ⌥ 切换：

层怎么进入放什么
基本层直接按13 个独立元音 + 33 个辅音 + 常用标点
⇧ 层Shift长元音 ā ī ū、反舌 ṭ ḍ ṇ、卷舌 ṣ ś、鼻音 ṃ ḥ
⌥ 层Option11 个元音附标 + 10 个送气辅音 kh gh ch jh th dh ph bh
⌥⇧ 层Option+Shift附标的长音形式、ṭha ḍha ñ、章节记号
Option 按右边那个。Keyman 在 macOS 上，右 Option 才稳定走键盘规则；左 Option 有时会被系统当成"输入变音符号"截走。

⇧ 和 ⌥ 到底怎么分工

整套键位只有一条规律，别的都是它的重复：

修饰作用例子
不按字母本身k→ka　r→ra　a→a
⇧给字母加 IAST 记号：长音、下点⇧a→ā　⇧t→ṭa　⇧n→ṇa　⇧s→ṣa　⇧r→ṛ
⌥换形态：元音→附标；辅音→送气 +h⌥i→i 附标　⌥k→kha　⌥t→tha
⌥⇧两者叠加：长附标 / 送气且反舌⌥⇧i→ī 附标　⌥⇧t→ṭha

同一条规律再按一次 = 长音。⇧r 是 ṛ，⇧r 再按一次就是 ṝ；⇧l 再按一次是 ḹ。附标同理：⌥i 连按两次、或 ⌥⇧i，都出 ī 附标。

所以 ṝ 不用记 Shift+v（那是我早先排错的例外，已撤掉）：现在是 ⇧r ⇧r。v 上只留一个极少用的备用位 ⌥⇧v。

看不见键位？打开屏幕键盘

Keyman 自带一张屏幕键盘：每个键上直接印着它会打出的悉昙字。初学不用背，照着按就行。

  1. 菜单栏点 Keyman 图标 → On-Screen Keyboard（屏幕键盘）。
  2. 按住 ⇧ 或 ⌥，屏幕键盘会跟着切到那一层。
  3. 按物理键盘上的键，屏幕键盘会高亮对应的位置。

5连字：辅音叠辅音

两个辅音之间没有元音时，前一个辅音要消掉自带的 a，用消元音号 -（悉昙字 𑖿）：

k + virama + ṣ = kṣ
𑖎𑖿𑖬 k -
规则很简单：每多一层辅音，就多按一次 -。三层叠字按两次，五层叠按四次。

11打错了怎么查

你看到的原因改法
