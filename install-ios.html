悉昙 IAST 输入法 · iPhone 安装说明

键盘包 Siddham-IAST-手机键盘.kmp（v1.6，已修标签：消元音号键显示为 -）· 手机上大约 6 步

先说结论

Mac 上那个键盘不能直接搬到 iPhone。iPhone 没有 macOS 那套 .keylayout 机制， 自定义输入法只能靠第三方键盘 App。所以我按 Mac 上那套键位，重新做了一个 Keyman 键盘包——Keyman 正是你 Mac 上已经在用的那个框架。

层内容与 Mac 版关系
默认层基本字母：k→𑖎、a→𑖀 与 Mac v1.5 逐键一致
⇧ 层送气音与长音：⇧k→𑖏 kha、⇧a→𑖁 ā 与 Mac v1.5 逐键一致
◌ 附标层 新增 元音符号（贴在辅音上）：◌𑖯 ◌𑖰 ◌𑖲 ◌𑖸 …
例：k + ◌𑖯 → 𑖎𑖯 kā		 Mac v1.5 缺这一层（11 个符号全缺），这里补齐
符号层数字、章节记号、变体字母 补齐后 92 个悉昙字符全部可打

连字用消元音号 -：k - ⇧s → 𑖎𑖿𑖬 kṣa。 这个键的标签就是 -，在默认层第三行第 8 个（m 往右两格）； 「附标层」第三行和「符号层」第二行也各放了一个，随手能按到。

包怎么传到手机都行：iCloud Drive、隔空投送、微信/邮件发给自己、数据线拷进 App 目录——文件是同一个，装出来的键盘也一样。唯一的差别只是「手机能不能找到这个文件」。

悉昙字显示成方框？最常见

原因：iPhone 自带没有悉昙字体（这个文种太冷门）。键盘包里的字体必须单独装成 「字体描述文件」才能全机可用。

有个现象容易让人误判：在 Keyman App 自己里面看，字体是正常的（App 内嵌了字体）， 但一旦把字打进备忘录、微信、Safari，就全变方框——因为那些 App 用的是系统字体。 所以：只要在别的 App 里是方框，就说明描述文件没装。

怎么补装

  1. 打开 Keyman → 重新走一次安装这个包（右上角 ⋯ → Settings → Install From File → 选那个 .kmp → Install）。安装过程中会出现 「Install」（安装字体）的提示。
  2. 点它 → 会跳到 设置 → 通用 → VPN 与设备管理 → 「已下载的描述文件」里出现 Noto Sans Siddham → 点 安装 → 输入锁屏密码 → 再点一次 安装（Consent 页）→ 完成。
  3. 回到 Keyman（提示「现在返回 Keyman」就点它）。

怎么确认装上了：设置 → 通用 → VPN 与设备管理 → 能看到一个字体描述文件。

如果那一栏是空的、也没有任何描述文件，就说明当时跳过了这一步，重装一次包即可补上。

手机上要做的（按顺序）

  1. 装 Keyman：App Store 搜 Keyman（SIL 出的，免费开源）。装完打开一次。
  2. 允许 Keyman 当系统键盘：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 在「第三方键盘」里选 Keyman。
    建议顺手把 Keyman 那一项里的「允许完全访问」打开（不打开也能用，但少些功能）。
  3. 拿到键盘包：打开「文件」App → iCloud Drive → Siddham-IAST-手机键盘.kmp。点它一下，选「用 Keyman 打开」。
    如果没弹出「用 Keyman 打开」，就打开 Keyman → 右上角 ⋯ → Settings → Install From File → 浏览到那个 .kmp。
  4. 点 Install 确认安装。
  5. 允许安装字体 关键·最容易漏：安装过程中会出现 「Install」（装字体）的提示。务必点——iPhone 本身没有悉昙字体，不装的话 打进别的 App 全是方框（在 Keyman App 里却看不出来，容易误判成"装好了"）。 点了之后会跳到：设置 → 通用 → VPN 与设备管理 → 已下载的描述文件 → Noto Sans Siddham → 安装 → 输密码 → 再点安装 → 完成 → 返回 Keyman。
    漏了不要紧，重装一次包就能补（见上一节）。
  6. 开始打字：任意输入框，点键盘左下角地球键 → 选 Keyman → 顶部若显示别的键盘，再点一次切换成 Siddham IAST。
自检：切到 Siddham IAST 后依次按 k ⇧t k - ⇧s，应该出 𑖎𑖘𑖎𑖿𑖬。
就算显示成方框也能验证：把那串字选中复制，发到聊天里／发给我—— 复制出来的是真正的 Unicode 字符，跟字体无关。我一看码位就知道键盘对不对。

键盘怎么用

底部一排按键（从左到右）：符号（切到数字/标点层）、菜单（地球，切输入法）、 ⇧（切到送气/长音层）、空格、◌（切到元音附标层）、回车。 输入框右侧的 ⌫ 是退格。

按 ◌ 之后点某个附标键，就会把符号贴到刚打的那个辅音上——写 𑖎𑖯（kā）就是 k 然后 ◌𑖯。

连字（消元音号 -）：默认层第三行第 8 键，标签 -； 附标层第三行、符号层第二行也有。打在两个辅音之间就成了叠字，例如 k - ⇧s → 𑖎𑖿𑖬。

符号层里的键直接显示字形（如 𑗆 𑗈 𑗊），它们是章节记号、 重复记号、变体字母——平时用不到，需要时去那一层找。

送气音（kh gh ch jh th dh ph bh）怎么打

长按对应字母键，会弹出送气版本，滑动选它就行（和 iOS 自带键盘长按出 é 是一样的操作）。

长按可选长按可选
kkh 𑖏ggh 𑖑
cch 𑖔jjh 𑖖
tth 𑖞 / ṭh 𑖙ddh 𑖠 / ḍh 𑖛
pph 𑖣bbh 𑖥
nñ 𑖗 / ṅ 𑖒sṣ 𑖬 / ś 𑖫

例：buddhakṣetre（佛土）＝ b → 点 ◌ 进附标层打 u → d → - → 长按 d 选 dh → 回字母层 k → 长按 s 选 ṣ → 附标层 e → t → - → r → 附标层 e

符号层里也有 th / dh / ṭh / ḍh 的独立键（第 3–4 行），但那层是给低频字符用的，日常还是长按快。

怎么撤销 / 换回

  • 停用：设置 → 通用 → 键盘 → 键盘 → 左滑 Keyman → 删除。默认键盘不受影响。
  • 删掉键盘包：在 Keyman 里 Settings → Installed Languages → 删掉 Sanskrit (Siddham)。
  • 删字体：设置 → 通用 → VPN与设备管理 → 删除那个字体描述文件。
  • 删掉 App 即完全还原，不会动系统里任何东西。
