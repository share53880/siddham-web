悉昙字输入法

用 IAST 罗马字直接打出梵文悉昙体。选你的系统，按步骤装一次，之后随时用。

你现在在微信里打开这页 —— 文件会下载失败。点右上角 ··· → 在浏览器打开，再回来下载。
先看清楚：Mac 上可以选「装 Keyman」或「用系统原生布局」，两种都行。
装 Keyman——三分钟搞定，键位和 iPhone 版完全一样，推荐给大多数人。
原生布局——不装任何第三方软件，但要注销重登一次，适合不想多装 App 的人。

方式 A · 用 Keyman（推荐）

1装 Keyman for macOS

Keyman 是 SIL 出的免费开源输入法框架，Mac 版官方下载：

去 keyman.com 下载官方 · 免费

装完打开一次，让它出现在菜单栏。

2装悉昙键盘包

下载 Mac 版键盘包.kmp · 120 KB
  • 下载完双击这个 .kmp，Keyman 会弹窗问是否安装 → 点 Install
  • 双击没反应？打开 Keyman → Configuration → Install keyboard → 选这个文件
  • 装完在菜单栏 Keyman 图标里切到 Siddham IAST

包里已经带了 Noto Sans Siddham 字体，不用另外装。

方式 B · 系统原生布局（不装软件）

1下载并解压

下载原生键盘布局.zip · 116 KB

解压得到一个文件夹，里面有安装脚本和字体。请不要在压缩包里直接双击。

2双击「安装.command」

  • 脚本只往你自己家目录写两个位置：~/Library/Keyboard Layouts/ 和 ~/Library/Fonts/
  • 不需要管理员密码，不碰系统目录
  • 如果提示「无法打开，来自身份不明的开发者」：在文件上右键 → 打开，再点一次「打开」

3注销重登，再添加键盘

键盘布局只在登录时被系统扫描，不注销就不会出现。

  • 注销一次（或重启），重新登录
  • 系统设置 → 键盘 → 文字输入 → 输入法 → 编辑… → 点 ＋
  • 在「印地语（Hindi）」分类下找 悉昙 IAST，添加；找不到就在列表上方的搜索框打 Siddham
  • 用 Control + 空格 或菜单栏图标切换
不想要了：文件夹里的「卸载.command」双击一下就清干净。

完整键位与用法：Mac 操作说明 →

顺序很重要：先装 Keyman，并把它加进系统键盘（第 1、2 步），再去下载键盘包。
顺序反了的话，包能装进去，但键盘不会出现在地球键里，很容易误以为这个包没用。

1App Store 装 Keyman

搜 Keyman（SIL 出的免费开源键盘 App），装完打开一次。

2把 Keyman 加进系统键盘

  • 设置 → 通用 → 键盘 → 键盘 → 添加新键盘
  • 在「第三方键盘」里选 Keyman
  • 点进 Keyman 那一项，把 允许完全访问 打开

3下载键盘包

下载 iPhone 键盘包.kmp · 121 KB

点完会存到「文件」App 里（一般在「下载」文件夹）。包里已带字体，不用另外装。

如果你是在微信里打开的这页：右上角 ··· → 在 Safari 中打开， 再点上面的下载。微信内置浏览器存下来的文件 Keyman 读不到。

4用 Keyman 打开它

  • 打开「文件」App → 找到刚下载的 .kmp → 点一下
  • 选「用 Keyman 打开」→ 点 Install
  • 没弹出？打开 Keyman → 右上角 ··· → Settings → Install From File → 选它

5装字体（最容易漏的一步）

iPhone 系统里没有悉昙字体。安装过程中 Keyman 会弹出一个 Install 提示，问你要不要装字体描述文件——务必点它。

  • 点完会跳到：设置 → 通用 → VPN 与设备管理 → 已下载的描述文件
  • 点进去 → 安装 → 输锁屏密码
漏了这步的症状：Keyman 里看着一切正常，一进备忘录、微信，字全变方框。

6开始打字

输入时点地球键切到 Siddham IAST。长按字母键出送气音（k 长按出 kh）。

  • Keyman 菜单 → Settings → Add Keyboard from Device

编辑器里怎么打

  • 打罗马字：底部框打 oṃ maṇi padme hūṃ，空格或回车，整段变悉昙插到正文
  • 打不出 ā ī ṭ ṃ ḥ：输入框下面有一排变音字母，点一下就插进去
  • 用字符表拼：叠字就「辅音 → 连写 → 下一个辅音」，重复就是三叠、四叠、五叠
