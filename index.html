悉昙字 · 手机上写

安卓没有悉昙字体。这里给一个自带字体的网页编辑器——打开就能写，写完存成图片发出去，谁都能看。

1打开编辑器（就这样，够了）

字体嵌在页面里（约 82 KB），不用装任何东西，不用联网。可以打罗马字转写，也可以用字符表一个字一个字拼；写完存图片 / PDF。

打开悉昙编辑器 不装东西 · 离线可用
建议：用 Chrome / Edge / 小米浏览器 / Safari 打开本页。在微信里点开的话， 点右上角「···」→ 在浏览器打开，否则下载和保存都会受限。

2想在微信里直接打字？（可选）

装 Keyman 键盘后，可以在微信、备忘录、短信里打出悉昙字符。多数人不需要，看下面那句再决定。

先说清楚：安卓系统里没有悉昙字体，所以装了键盘，在微信里照样显示方框。 键盘只保证「发出去的字符是对的」，不能让你看见。要看见，还是用上面的编辑器。

第一步 · 装键盘引擎（SIL 官方原包，未修改）：

下载 Keyman 安卓版 APK · 12.3 MB

下不动的话用官方直链： downloads.keyman.com

第二步 · 导入悉昙键盘包（.kmp）：

下载悉昙键盘包 .kmp · 121 KB
  • Keyman 菜单 → Settings → Add Keyboard from Device
  • 选这个 .kmp → Install
  • 装完在 设置 → 语言和输入法 里启用 Keyman

编辑器里怎么打

  • 打罗马字：在底部框里打 oṃ maṇi padme hūṃ，空格或回车，整段变悉昙插到正文
  • 打不出 ā ī ṭ ṃ ḥ：输入框下面有一排变音字母，点一下就插进去（末尾 Aa 切大写）
  • 用字符表拼：点开底部的字符表，每个键都标了发音（ka / kha / ga…）。 叠字就「辅音 → 连写 → 下一个辅音」，重复几次就是三叠、四叠、五叠
  • 导出：存图片（PNG，长按保存）· 存 PDF（打印里选「另存为 PDF」）
